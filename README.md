本仓库只存**二进制成果物**，两者配合构成完整交付。

## 作品说明文档的结构

作品介绍文档按赛事规范第四节六段组织：项目定位 / 主要创新 / 技术或创作实现 /
成果状态（已完成·正在完善·后续计划三档）/ **团队分工与原创贡献**（成员A、成员B 匿名表述）/
应用场景与测试结果。全部文字材料在代码仓库 `docs/作品集/参赛/`。

## 已完成的合规核查

- **匿名化**：提交材料内不含学校、团队成员、指导教师等身份信息；PPT 为图片型无文字层。
- **源码卫生**：不含 API Key / Secret；已清理本机绝对路径；打包时排除 `.env` 与数据库文件。
- **可运行性**：在打包副本上实测 `uv sync --extra openai && uv run pytest -q` → **284 passed**。
- **ZIP 兼容性**：文件名带 UTF-8 标志位（Windows 解压不乱码），无 `__MACOSX/` 垃圾条目。
