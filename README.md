# 知迹 · 参赛成果归档

**全国大学生数字媒体科技作品及创意竞赛**（赛道十三 · 智慧教育）参赛成果归档。

代码仓库在 [`Baicaicn23/StudyGraph`](https://github.com/Baicaicn23/StudyGraph)——
本仓库只存放**二进制成果物**（视频、PPT、截图、打包文件），两者配合构成完整交付。

---

## 目录

| 目录 | 内容 | 说明 |
| --- | --- | --- |
| `01_作品汇报PPT/` | `知迹_汇报.pptx`（18 页）+ `P01–P18.png`（逐页源图） | PPT 为**纯图片型**（每页一张 PNG，无文字层）：排版绝对可控，代价是文字不可检索、改字号需重出图 |

| 材料 | 提交方式 |

## 已完成的合规核查

- **匿名化**：打包包内不含学校、团队成员、指导教师等身份信息；PPT 为图片型无文字层；视频抽帧确认无身份信息。
- **源码卫生**：不含 API Key / Secret；已清理本机绝对路径；打包时排除 `.env` 与数据库文件。
- **可运行性**：在打包副本上实测 `uv sync --extra openai && uv run pytest -q` → **284 passed**。
- **ZIP 兼容性**：文件名带 UTF-8 标志位（Windows 解压不乱码），无 `__MACOSX/` 垃圾条目。
